# Before Midnight: scrollable introduction, longer version (about 2,000 words)

Open `index.html` in a browser. No server and no internet connection are needed. Everything is in this folder.

- `index.html`: the page (content and theme)
- `shared/engine.css`, `shared/engine.js`: scroll mechanics (sticky image stage, year and clock rail, four-blank tracker, night mode)
- `shared/fonts.css` and `shared/fonts/`: self-hosted fonts (see `shared/fonts/LICENSES.md`)
- `assets/`: twelve optimized images. Sources and licenses are listed at the foot of the page and in `assets/CREDITS.md`.

Best viewed on a laptop or projector (landscape, 1280 px wide or more). It also works on phones and tablets.
To project it for a class, open it full screen and scroll with the arrow keys or a presentation remote.
Zip this folder to send it to someone.
