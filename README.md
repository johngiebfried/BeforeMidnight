# Before Midnight: pre-game introduction

Static site. `index.html` is the title page with a choice of two scroll introductions.

- `shorter-introduction/`: about five minutes.
- `longer-introduction/`: about nine minutes.

Each folder is self-contained (its own `assets/` and `shared/`). The title page uses `fonts/` and `fonts.css`. No build step, no network needed. Open `index.html` in a browser, or serve the repo root with GitHub Pages (Settings, Pages, deploy from `main`, root).
